# Feature name

## Summary

One or two sentences: what this feature is for and who uses it.

## Behavior

- What the user does, and what happens in response.
- One bullet per action, including keyboard shortcuts and menu items.

## Edge cases

- Empty, full, or unusual states (no tabs, hundreds of tabs, a page that never loads).
- What happens after a restart or a crash.

## Acceptance checks

1. Starting state, the step to take, the expected result.
2. Each check is something a person or an agent can run by hand.

## Out of scope

- Related behavior this spec deliberately leaves out, with a pointer to the spec that covers it if one exists.
